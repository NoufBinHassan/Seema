# سِيماء \| Seema

مرصد السلوك الرقمي لكشف الحسابات غير الطبيعية

------------------------------------------------------------------------

## نبذة عن المشروع

سِيماء هو نظام ذكي ومبتكر لتحليل السلوك الرقمي للحسابات عبر مختلف
المنصات، بهدف رئيسي هو كشف الحسابات غير الطبيعية أو المشتركة التي قد
تؤثر على دقة الإحصاءات الوطنية.

يعتمد النظام على تحليل متعمق لأنماط النشاط، التنقل الجغرافي، الإنتاجية،
والتقييمات لاكتشاف أي سلوك غير منطقي أو مشبوه، ومن ثم تصنيف الحسابات
بناءً على درجة الاشتباه.

------------------------------------------------------------------------

## المنهجية المستخدمة

يعتمد النظام على مجموعة من تقنيات تحليل البيانات وكشف الشذوذ، منها:

-   تحليل السلوك (Behavioral Analysis)
-   كشف الشذوذ (Anomaly Detection)
-   Isolation Forest
-   Z-Score
-   تحليل GPS باستخدام Haversine Formula
-   دمج البيانات من مصادر متعددة

------------------------------------------------------------------------

## المتطلبات التقنية

قبل تشغيل المشروع تأكد من توفر:

-   Python 3.10 أو أحدث
-   اتصال بالإنترنت (لتثبيت المكتبات)

------------------------------------------------------------------------

## تثبيت المكتبات

``` bash
pip install -r requirements.txt
```

------------------------------------------------------------------------

## تشغيل المشروع

``` bash
python -m streamlit run lastapp.py
```

ثم افتح الرابط في المتصفح: http://localhost:8501
